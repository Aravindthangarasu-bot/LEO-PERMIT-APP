🎭 Use Case Diagram
All actors and their interactions with the LEO system
🏠
Customer
Property owner applying for permits
  • Sign Up with Mobile OTP
  • Log In (existing account)
  • View Dashboard (13 service tiles)
  • Submit New Permit Application (5 KPBR services)
  • Upload Required Documents (4 common docs)
  • Select Service Provider (KPBR-filtered)
  • Propose 3 Site Visit Dates
  • Review & Approve/Reject Plan
  • Request Plan Revision with Comments
  • Track Application Timeline
  • Receive Notifications (with contact info)
  • Download Approval Letter
  • Terminate Project
  • View Historical Applications
🏗️
Service Provider
KPBR-licensed permit approver
  • Self-Register (2-step form)
  • Log In with Mobile OTP
  • View Assigned Applications
  • Acknowledge Request (notify customer)
  • Verify Customer Documents
  • Report Document Issues
  • Select Site Visit Date (from 3 options)
  • Conduct Site Measurement
  • Upload Building Plan PDF
  • Submit to Local Authority
  • Upload Authority Approved Documents
  • Add Office Staff Members
  • Assign Work to Staff
  • Manage Staff (activate/deactivate)
  • View Licence Expiry Reminders
  • Decline / Terminate Project
👨‍💼
Office Staff
Provider's associate handling assigned work
  • Log In via "Office Staff" portal
  • View Only Assigned Applications (isolated)
  • Review Customer Details & Documents
  • Update Application Status
  • Add Notes / Remarks
  • Request Additional Documents
  • Trigger Customer Notifications
  • Cannot access other provider's data
  • Cannot access unassigned applications
  • Blocked if account deactivated
🔐
Super Admin
Platform administrator with full access
  • Log In (secure OTP)
  • View System Dashboard (all stats)
  • Review Provider Registration Requests
  • Approve / Reject Provider Applications
  • View KPBR Licence Details & Limits
  • Monitor Licence Expiry Alerts
  • Suspend / Reactivate Providers
  • Add Providers Manually (4-step)
  • View All Applications (all customers)
  • Filter & Search Applications
  • Assign Providers to Applications
  • View Provider Performance & Ratings

Complete state machine for every permit application from submission to completion
Status State Machine
flowchart TD
  START([Customer Submits Application]) --> P

  P["🟣 PENDING\n Submitted, awaiting provider"]
  P --> UR["🔵 UNDER REVIEW\n Provider acknowledged\n Customer notified with contact"]

  UR --> DR["🟡 DOCS REQUIRED ⚠️\n Provider flagged issue\n Customer must re-upload"]
  DR --> UR

  UR --> SVS["🟣 SITE VISIT SCHEDULED\n Customer proposed 3 dates\n Provider selected one"]
  SVS --> SVC["🟣 SITE VISIT CONFIRMED\n Date locked in\n Both parties notified"]
  SVC --> PP["🔵 PLAN PREPARATION\n Provider measuring & drafting"]
  PP --> PU["🔵 PLAN UPLOADED\n Plan PDF sent to customer"]

  PU --> CR["🟡 CLIENT REVIEW ⚠️\n Customer must approve or reject"]
  CR --> RR["🟠 REVISION REQUESTED\n Customer sent comments\n Provider must revise"]
  RR --> PU

  CR --> AR["🔵 AUTHORITY REVIEW\n Application submitted to authority"]
  AR --> AA["🟢 AUTHORITY APPROVED ✅\n Approval number generated\n Provider uploads signed docs"]
  AR --> AJ["🔴 AUTHORITY REJECTED\n Provider must revise plan"]
  AJ --> PP

  AA --> DONE([Project Complete 🎉])

  P --> T["⚫ TERMINATED\n Declined by client or provider"]
  UR --> T
  SVS --> T
  PP --> T
